# Delta Promotional Website

Delta is a student software development team at ISMT College, University of Sunderland. We build accessible, cost-effective interactive training platforms for logistics and warehousing organizations.

This repository contains the source code for the Delta promotional website, built for the CET257 Enterprise Project 2025–2026.

## Overview

The website showcases our team, our mission, and our projects. It highlights our commitment to building software around the people who use it, with a strong focus on:
- **Web Application Development**: Modern, browser-based applications accessible anywhere.
- **Accessibility-First Design**: WCAG 2.1 Level AA compliance.
- **Secure, GDPR-Ready Systems**: Built with UK GDPR compliance as a foundation.

## Latest Project: SafeMotion
Our active project is **SafeMotion**, an interactive manual handling risk and training platform for a logistics & warehousing company in the automotive sector. It includes:
- 360° Virtual Warehouse Training
- Hazard Identification Exercise
- 10-Question Timed Assessment
- Automated Digital Certificate
- Real-time Admin Compliance Dashboard
- Department-Level Progress Tracking
- Automated Training Reminders
- Zero Licence Cost to Client

## Structure
The website is built using standard web technologies:
- `index.html`: The main landing page.
- `about.html`: Information about the Delta team.
- `work.html`: Details about our projects, including SafeMotion.
- `contact.html`: Contact information and form.
- `style.css`: The stylesheet for the website.
- `assets/`: Directory containing images and other static assets.

## Core Principles
1. **Accessibility by Default**: WCAG 2.1 AA is our minimum standard.
2. **Transparency with Clients**: Clear communication and documentation.
3. **Zero Unnecessary Cost**: Exclusive use of open-source tools.
4. **Test Before You Claim**: Rigorous testing against defined criteria.
